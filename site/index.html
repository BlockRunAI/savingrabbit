How it works

Measure, replay, route.

01 · MEASURE

Cost per merged PR

Pulls spend from each vendor's own admin API and reads which agent and model wrote each merged PR from the Co-Authored-By trailers your agents already leave. Reports by tool, model and team.

02 · REPLAY

Which tasks need the top model

Re-runs real tasks on cheaper models through one BlockRun key, records what each call cost, and checks every answer against the output your team accepted.

03 · ROUTE

Switch with evidence

Picks the cheapest model that held your quality bar and writes the /model and /exclude settings for ClawRouter, the open-source router.

Built to be trusted with keys

Read it in one sitting.

One Python file, standard library only. It runs on your machine, talks only to the vendors you point it at, and keeps no account and no telemetry.

  • Read-only. GET requests and one read-only search. It never writes to a vendor.
  • Teams, not people. It reads per-person data where vendors publish it that way, and reports only by team.
  • Keys stay in your shell. Read from environment variables, never written to disk or printed in errors.
  • Honest about limits. A merged PR is not value, and cost per PR is a window ratio. The README says so.

FAQ

Questions teams ask first

How much does Claude Code cost per pull request?

It varies widely by team and model, which is why it's worth measuring. Run pull-local for yourself, or pull-claude-code plus pull-github for a team, then report.

How do I measure the ROI of Cursor, Copilot or Codex?

Connect each tool's admin API and compare cost per merged PR across tools. Copilot is billed per seat, so its cost is seats times your seat price.

Can I track AI coding spend by team without tracking individuals?

Yes. Map emails and GitHub logins to teams in a CSV. Spend and merged PRs roll up to teams, and the report never shows a person.

Does it send my code or prompts anywhere?

No. It reads usage counts and git metadata locally. Only the optional replay command sends the sample prompts you choose to BlockRun's gateway, so use samples with secrets removed.

Is it free?

Yes. Apache 2.0, including commercial use inside your company. Replays run on BlockRun at the cost of the calls.
